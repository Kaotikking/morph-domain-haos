# Morph Nine-Core v1

Dustdevil is the first live-born Morph to develop all nine portable Cores. This
one-time event is called **Inward Bloom** and occurs while Dustdevil is frozen
in the Void. The event does not advance time, change custody, replace DNA, or
alter lineage.

The nine Cores are Platform, Root, Memory, Knowledge, UI, Audio, Personality,
Modular, and Cloud. A Morph has no Kernel Core: its active Frame owns hardware
execution and the Kernel boundary.

Dustdevil's Audio Core stores a deterministic elemental voice recipe rather
than an audio recording. Immutable identity, birth lineage, genome digest,
element voice, and trait modifier derive its stable signature. Expression can
later vary the rendering without changing the voice identity.

`trait_stage: 0` marks the historic source trait. Mutable expression stages
remain bounded to 1-5. The Root Core records Dustdevil as `first-whole`, with
the naturally developed `inward-bloom` emergence event.

The live operation is deliberately narrow: only Dustdevil's exact Morph ID,
generation, HAOS authority, predecessor digest, and Void stasis are admitted.
The predecessor snapshot is retained for rollback and replay is idempotent.
This is not a general Void write path; ordinary Morph repairs remain Code Haven
operations.
