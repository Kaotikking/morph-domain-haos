# Morph Engine nine-Core foundation

**Public world:** MorphDomain  
**Runtime:** Morph Engine  
**Schema:** `serein.morph-engine.v1`  
**Shape:** one local-first process with nine strict internal Core records  
**Kernel:** prohibited

MorphDomain remains the five-place world: Void, Code Haven, Horizon, Nursery,
and Serein Gardens. The Morph Engine applies that world's laws. It does not
rename, replace, or fork MorphDomain.

## Canonical order and ownership

1. **Platform** — runtime, storage, clock, life schedule, and detected host
   capabilities. Platform decides what the host can execute, never who a Morph
   is.
2. **Root** — immutable identity, Lineage Capsule and digest, current authority,
   and transaction state. Morph identity, parentage, founder ancestry,
   birth-device lineage, generation, and capsule may not be rewritten.
3. **Memory** — append-only Chronicle, family truth, directional relationships,
   and accumulated experience. Established keys cannot disappear, counters
   cannot decrease, and ordered records retain their prefix.
4. **Knowledge** — attributable environment observations, preferences, and
   learned patterns. Knowledge may inform expression but cannot rewrite Root.
5. **UI** — Form, elemental rendering, opaque egg rendering, animation, and
   accessibility. UI is projection, not identity.
6. **Audio** — elemental voice, battle cry, and remembered audio experience.
   Audio capability may disappear from a frame without erasing audio truth.
7. **Personality** — mood, traits, social disposition, and compatibility.
   Transient presentation cannot rewrite DNA.
8. **Modular** — combination rules, frame-capability adapters, and admitted
   extensions. Optional hardware paths live here behind Platform evidence.
9. **Cloud** — transfer, custody, reconciliation, and SERN capsule transport.
   Network success alone never changes ownership.

Every Core carries its own exact v1 schema and exact top-level fields. Unknown,
missing, extra, or non-JSON state fails closed.

## Five cooperating facets

- **Life:** Platform, Memory, Personality.
- **Social:** Memory, Personality.
- **Expression:** UI, Audio, Personality.
- **Combination:** Root, Memory, Modular.
- **Reflex:** Platform, Root, Memory, Cloud.

A facet may write only those admitted Cores. This is a write boundary, not a
license to alter every field inside them. Root immutability and Memory
monotonicity apply to every facet, including Combination and Reflex.

## Graceful frame projection

Frames and Android consume Morph Engine truth; they do not define it. A
destination without display or audio receives `remembered-not-rendered`
projection for that capability. The canonical nine-Core record stays complete,
allowing the Morph to express the capability again on a suitable frame.

## Repair boundary

Code Haven remains the only Morph-state, DNA, and presentation write boundary.
A repair reflex must provide:

1. one unique detection signature;
2. one admitted disposition;
3. allowlisted effects only;
4. all immutable-truth guards in canonical order;
5. a bound predecessor digest before any effect;
6. an executable rollback strategy;
7. an append-only Chronicle event;
8. every required acceptance readback.

Deterministic representation or derived-presentation repair may be automatic.
Ambiguous successors require an HAOS administrator and have no automatic
effect. Identity, lineage, parentage, birth-device, custody, or authority
conflicts isolate in Void and deny breeding and transfer.

## Installation and evolution

Installing a Morph Engine release does not migrate, backfill, move, rename,
transfer, or rewrite a Morph. An existing Morph adopts a new state generation
only through a separately named Code Haven transaction with preserved
predecessor and acceptance evidence.

## Capability profiles remain downstream

BASE and ACCELERATED hardware profiles will be implemented after this
foundation. CPU SIMD, multicore CPU, iGPU, discrete GPU, ARM GPU, NPU/tensor,
and hardware codecs will be admitted per function. Hardware may enrich
presentation and perception but can never alter identity, DNA, lineage, life,
Memory, custody, or authority. Losing acceleration must fall back to BASE.
