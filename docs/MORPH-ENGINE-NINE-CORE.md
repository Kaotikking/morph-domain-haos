# Morph Engine nine-Core architecture

**Public product name:** Morph Engine  
**World contract:** MorphDomain  
**Runtime shape:** one efficient process with nine internal Core boundaries  
**Kernel:** absent by law

MorphDomain remains the five-place world: Void, Code Haven, Horizon, Nursery,
and Serein Gardens. This change does not rename or replace it. Morph Engine is
the implementation that runs its laws.

## Nine internal Cores

1. Platform — runtime, storage, clock, life scheduling and host capability.
2. Root — Morph identity, Lineage Capsule, authority and transaction ordering.
3. Memory — Chronicle, family truth, directional relationships and experience.
4. Knowledge — learned environment, preferences and attributable patterns.
5. UI — Form, elemental rendering, eggs, animation and accessibility.
6. Audio — elemental voice, battle cry and remembered audio capability.
7. Personality — mood, traits, social disposition and compatibility.
8. Modular — combination engine, frame capabilities and admitted extensions.
9. Cloud — transfer, custody, reconciliation and SERN capsules.

## Five cooperating engine facets

- Life coordinates Platform, Memory and Personality.
- Social coordinates Memory and Personality.
- Expression coordinates UI, Audio and Personality.
- Combination coordinates Root, Memory and Modular.
- Reflex coordinates Platform, Root, Memory and Cloud.

A facet may write only its admitted Cores. Root identity and lineage remain
immutable. Unsupported frame capabilities produce graceful presentation
degradation while retaining the complete canonical nine-Core state.

Users see one Morph Engine. The internal Core model exists to keep every host,
frame, repair, transfer and future module aligned with DNAv1.
